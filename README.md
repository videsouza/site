# Número Imaginário — site de livros e artigos

Site estático (HTML/CSS/JS puro) para divulgar livros e artigos do projeto
**Número Imaginário**, hospedado no GitHub Pages.

## Estrutura

- `index.html` — página inicial
- `livros.html` — livros e séries/cursos
- `artigos.html` — lista de artigos (com filtro por assunto)
- `sobre.html` — sobre o projeto
- `contato.html` — contato
- `css/style.css` — folha de estilo única
- `js/main.js` — interações (menu móvel, filtro, reveal)
- `assets/images/` — imagens (ver abaixo)
